# QR Code Generator

A simple and responsive **QR Code Generator** built using HTML, CSS, and JavaScript. The project allows users to generate QR codes dynamically from their input through a clean and easy-to-use interface.

## ✨ Features

* Generate QR codes dynamically from user input
* Simple and intuitive user interface
* Responsive layout for different screen sizes
* Interactive functionality using JavaScript
* Lightweight frontend application with no backend required

## 🛠️ Technologies Used

* HTML5 — Page structure and content
* CSS3 — Styling, layout, and responsive design
* JavaScript — Dynamic QR generation and user interaction
